## 2. 一句话结论

**针对"停机锁机、姿态随机"的风机，用俯视图+正视图的 YOLOv5 视觉管线解算偏航角/相位角/仰角/锥角并精确定位叶尖，在几何骨架面片化模型上做"混合采样→多约束筛选→贪心覆盖优化→冗余融合"的全表面航点规划，再以"碰撞检测插过渡点+三次多项式插值+位置/速度加权混合控制"实现安全平滑飞行，最后用"霍夫直线+k-means"的视觉反馈闭环微调云台使叶片居中**——全程仅停机工况，仿真（Gazebo/PX4/XTDrone）+ 校园微缩风机实物验证，未进真实风场。

它不是一篇"航迹优化算法"论文（没有 A*/RRT*/PSO），规划本体是**采样-筛选-贪心集合覆盖**；它的真正分量在**视觉参数获取链路**（叶尖定位）和**控制细节的工程数值**上。

## 3. 研究问题与定位

### 3.1 前人做到哪（论文的综述口径，p3–6）

- 风机巡检主流是**半自动**（操作员遥控），自主巡检研究大多**只针对静止风机**（p4，文献[25-29]）。
- 典型路线是**逐点拍摄式**：沿叶片固定距离飞行拍摄（p5，图 1-5）。论文批评其四条不足（p5）：
  1. 未利用云台自由度与变焦；
  2. 只能拍迎风/背风面，前后缘、其他部件覆盖不到；
  3. 泛用性低，只适用特定姿态（如倒"Y"）；
  4. **部分航点落在风机工作区域内，有相撞风险**。
- 对比算法（其导师组的两篇前置工作）：算法一 = 文献[37]（焦嵩鸣等 2023，叶尖定位），算法二 = 文献[57]（焦嵩鸣、张彪，局部图像叶尖定位）。

### 3.2 它的切口

四个"以往方法没有"的点，构成全文的四个贡献：

1. **姿态随机** → 俯视图定向 + 位姿修正 + 正视定位 + 多参数（仰角/锥角）修正，叶尖精确定位（第 3 章）；
2. **建模效率** → 几何骨架拓展的面片化模型（192 面片，可量化分析），不做点云重建（§3.4）；
3. **航点自由度低/不安全** → 五自由度航点 [x,y,z,θg,ψg] + 多约束筛选 + 覆盖率-成像质量-数量多目标优化（§4.2）；
4. **飞行不连续/图像偏移** → 混合控制 + 云台对正策略（§4.3–4.4）。

**关键假设（必须记住，影响全部可迁移性判断）**：p11 明确"为确保巡检的安全性，必须使风机处于停机工况……假设顺桨状态下桨距角误差可忽略不计，即单个桨叶平面始终与风轮平面保持垂直（90°）"。即**整机全程锁机静止**；§6.2 承认无法对运行状态风机定位巡检，叶片微弱摆动也未建模。

## 4. 技术路线与方法（分章详述）

### 4.1 第 2 章：基础理论（p9–17）

- **风机几何参数**（p10，图 2-2）：风轮轴线、风轮平面、风轮直径、**风轮仰角**（轴线与水平面夹角）、风机偏航角、叶片中心线、**叶片相位角**（中心线与相位基准线夹角）、**叶片桨距角**（顶端弦线与旋转平面夹角）、**叶片锥角**（中心线相对垂直于风轮轴的平面的倾角）、**叶片翘角**（中心线与竖直面夹角，由仰角和锥角决定）。
- **禁飞区定义**（p10）：以**轮毂中心为球心、叶片长度为半径的球体**。这是全文安全模型的基石（与 wt_inspection 的"叶轮圆盘"模型不同，见 §6）。
- **工况分类**（p11）：停机（自动停机/锁机）、运行（启动/欠功率/满功率）、顺桨（桨距角 0°→90°，叶面⊥风轮面）、逆桨。巡检只做**停机+顺桨**。
- **六个坐标系**（p13–14）：世界 {W}（上电点为原点，X 东 Y 北 Z 上）、机体 {D}、相机 {C}、图像 {xy}、像素 {uv}、风机 {F}（原点=轮毂中心，XF=机舱→轮毂水平向）。式(2-1)/(2-2) 给出像素→世界的完整链（内参 K × R_C/D,T_C/D × R_D/W,T_D/W [× R_D/F,T_D/F]）。
- **目标检测**：YOLOv5s（四版本中最轻），理由是 Gazebo 仿真里 30FPS 实时。检测五类：风机整体 W、轮毂 H、机舱 C、桨叶 B、塔筒 T（p18）。

### 4.2 第 3 章：叶尖定位与建模（p18–33）

#### 4.2.1 四步流程（p19，图 3-2）

**① 俯视定向** —— 无人机飞到俯视拍摄点 `(x_t^W, y_t^W, h_hub + d_final)`（塔筒中心水平坐标视为轮毂粗坐标；风电场对 `h_hub` 和塔筒中心坐标有台账准确值，p20）。俯视点距离约束（式 3-1，p20）[V]（已回 PDF 核对）：

```text
d_final = max{ d_s, d_VFOV, d_HFOV }
d_s     ≥ L_blade + h_hub                    ← 安全距离 ≥ 叶长+轮毂高（从头顶拍全风机）
d_VFOV  = (h_cam/2) / tan(VFOV/2)            ← 覆盖全高的最小距离
d_HFOV  = (w_cam/2) / tan(HFOV/2)            ← 覆盖全宽的最小距离
h_cam ≥ 2·L_blade ,  w_cam ≥ 2·L_blade
```

偏航角求取——**轮毂-机舱中心线法**（式 3-2，p21）：取轮毂中心像素点 O 与机舱中心像素点 M，构造向量 MO 与像素 u/v 轴负向单位向量 e1/e2，`yaw_f = ±arccos(MO·e1 / |MO||e1|)`，符号由 `MO·e2` 的正负决定。

**冗余计算机制**（p21，本文的可靠性核心设计）：叶片可能遮挡轮毂或机舱。二者均可见 → 用中心线法；**任一不可见 → 回退"叶片斜率权重法"**：对叶片预选框内做 Hough 直线检测得 j 条线段，按"像素长度 l_n × 长度系数 × 斜率 k_n"加权拟合出一条斜率 k0 的直线（式 3-3，p21），风轮轴线取其垂线。文中称该机制能规避两类对比算法的异常（p31）：轮毂像素占比过小导致**往复调节循环（可达 8 min）**、轮毂缺失导致**修正点持续偏离**。

**② 位姿修正器**（p22–23，图 3-4）：两个同时满足才认为就位——轮毂中心位于图像中心 + 风轮轴线垂直于图像横轴。工程参数 [V]（p22）：

- 修正**缓冲时间 5 s**（每次修正后悬停，期间同步计算下一次修正量）；
- 输出**限幅**：偏航修正限制在 (−π, π]，位移修正限制在 **±10 m**；
- 位置判据：Δx、Δy 均 **< 1 m** 即认定位于轮毂正上方（式 3-5 由像素差 (u_hub−u0, v_hub−v0) 经相机模型闭式解出世界系修正量，p23）；
- 姿态判据：|yaw_d − (yaw_f − π)| **≤ 0.0873 rad（±5°）** 即认定与风机相向（式 3-6 给 yaw_d = yaw_f ± π 的规范化）。

**③ 正视定位**（p23–24）：飞至"沿风机朝向一定距离的轮毂中心等高点"拍正视图，提取叶尖像素坐标 (u_i, v_i)，经式(2-1) 得叶尖粗略世界坐标；由叶片中心线斜率算各叶片测量相位角，再按**相位角加权**（式 3-7，p24）：

```text
β'_i = β_i / 3 + 2π(i−2)/3 ,  i = 1,2,3
```

即利用三叶片互成 120° 的结构先验做冗余平均。`[?]` 式中系数 1/3 与 2π/3 的组合在文本提取中略去了一个公共因子（PDF 原页同样只见此形式），其推导意图是"三片叶片测得的同一相位应一致，取均值"，论文未展开。

**④ 多参数修正**（p24–26）——全文最有几何含量的一节。三种风机简化模型：

- **I 型**（理想）：仰角=锥角=0，叶尖=粗略坐标。实测三轴平均误差 **≈2.6 m**（p33），而叶片最大宽度仅 2.04 m——**误差大于叶宽，可能造成巡检点大偏移甚至安全事故**（论文原话，p33）。
- **PE 型**（相位角-仰角）：锥角=0，正视图里风轮平面投影为**椭圆**（三叶尖+轮毂中心最小二乘拟合）。相位 0° 处叶片投影长=实长（椭圆长轴 W m），相位 90° 处=实长×cosα（短轴 W n），故（式 3-8，p25）：

```text
α  = arccos( W n / W m )                    ← 风轮仰角
θ_i = arctan( cos(β'_i) · tan(−α) )          ← 叶片翘角
```

叶尖修正坐标（式 3-9，p25）：`[x', y', z']^W = L·(R_F^W)^{-1} · [sin θ_i, cos θ_i · sin β'_i, cos θ_i · cos β'_i]^T`。
- **PEC 型**（相位-仰角-锥角）：翘角关系变为（式 3-10，p25）`θ_i = arctan(cos β'_i · tan(−α)) + γ`；再由三叶尖像素长度换算世界系投影长度 W l_i，得三个方程 `cos θ_i = W l_i / L`（式 3-11），**最小二乘联立解出仰角 α'、锥角 γ'、翘角 θ'_i**。θ_i 的正负号由分界相位角（式 3-12，p25）`β_bound = arccos( tan(−γ)/tan(−α) )` 分段判定（式 3-13）。

三种模型仿真对比（p32–33，表 3-4/3-5，真实仰角 8°、锥角 2°）：PE 型测得 12°/0°（结构误差大），**PEC 型 8.43°/2.11°**；叶尖三轴平均误差 I 型 ≈2.6 m、PE ≈1.4 m（−46%）、**PEC ≈1.1 m（−57.7%，绝大部分亚米级）**。

#### 4.2.2 几何骨架三维建模（p26–28）

- **骨架**：连接塔底中心 P_tower—轮毂 P_hub（塔筒轴线，高 H_tower=‖P_hub−P_tower‖）与轮毂—三叶尖（叶片轴线集 L_i）。
- **几何拓展**：沿塔筒轴扫掠半径 r_tower 成圆柱；沿叶片轴扫掠半径 r_i（=叶片最大宽度）成初始圆柱；**布尔差剔除叶片与轮毂球（半径 r_hub）的干涉**：C'_i = C_i \ B(P_hub, r_hub)（式 3-17/3-18，p27）。
- **三角面片化**：塔筒沿轴 N_z 段 × 圆周 N_θ 份、每份对角线一分为二；叶片同理 N_b 段。**两端圆面不分割**（塔底不可视、叶顶为锥点）。默认 N_z=4、N_θ=6、N_b=4 → **塔筒 48 + 桨叶 144 = 192 面片**（p27）。
- **面片四属性**（p28–29）：顶点集 V_j、中心 c_j=(v1+v2+v3)/3、**外向法向量 n_j**（规定风机外表面为正）、面积 A_j=½|(v2−v1)×(v3−v1)|。

> 注意：叶片被建成了**等半径圆柱**，不是真实翼型；面片是均匀圆柱网格。这是"可量化、够用"与"几何保真"之间的明确取舍。

#### 4.2.3 仿真验证（p29–33）

- 平台：ROS + Gazebo + PX4 + XTDrone，机型 Typhoon H480 + CGO3 云台（最大速度 13.5 m/s，HFOV 60°，VFOV 45°，960×720@30FPS，云台俯仰 −90°~15°）。风机：轮毂高 71.29 m、叶长 39.10 m、叶片最大宽 2.04 m、仰角 8°、锥角 2°（表 3-1，p29）。
- 数据集：仿真采集 800 张 960×720，5 类，7:3 划分，mAP **0.991**。
- 与算法一/二的对比（N=30，表 3-2/3-3，p30–31）：
  - 偏航角误差 **3.5°**（算法一 7.2°、算法二 6.8°，降低 51.4%/48.5%）；
  - 相位角平均误差 **2.24°**（算法一 4.92°、算法二 3.10%）；算法二在正"Y"型附近会**相位角缺失**（其剔除塔筒附近线段）；
  - 单次修正平均用时 3.78 s（对手 9.34/6.15 s）；单次调整（含缓冲）9.75 s；
  - **修正异常次数 0**（对手 3 次和 2 次，源于轮毂不可见）；
  - 代价：本文方法要先飞俯视点再飞正视点，**整体时耗偏长（该段 14~17 s）**，且平均调整次数 1.63 反而多于算法一的 1.30 `[?]`（论文未解释这处对比劣势，只强调时间短）；
  - 算法一/二的初始观测点必须在风机朝向正半平面（否则识别不到轮毂），本文用俯视图消除了这一限制。

### 4.3 第 4 章：航点规划与控制策略（p34–54）

#### 4.3.1 航点四阶段流水线（§4.2）

**航点状态 = 五个自由度** [x, y, z, θ_g, ψ_g]（p36）：云台偏航与机头偏航冗余，只取云台偏航；云台滚转由飞控保持；**定焦假设**（焦距固定不变）。

**① 混合采样**（p34–35，式 4-1/4-2）：以轮毂-塔筒轴线为中心线的圆柱采样域，`H_scan = H_tower + 2L_i`，`R_scan = 2L_i`；极坐标分层 N_θ、N_r、N_h 均匀布点，**每个均匀点再生成若干带高斯扰动（径向 σ_r、角度 σ_θ、高度 σ_h）的随机点**。仿真参数：H_scan 151 m、R_scan 80 m、N_r=6、N_h=8、N_θ=24 → 均匀 1152 点 + 每点随机 9 个 = **初始集 P_origin 共 11520 点**（p48）。

**② 安全性筛选**（p36，式 4-3/4-4）：
- 面片距离：航点到任一面片的（法向）距离 `n_j·(q0−c_j)/‖n_j‖` 小于最小飞行距离 d_s 则删除 `[?]` 原文未写绝对值符号、也未说明面片背面（负值）的处理；
- **剔除高度 20 m 以下点位**（低空约束）；
- **禁飞球**：以 P_hub 为球心、半径 L_i 的球体内的点删除。

**③ 可巡检性筛选**（p36–38，式 4-5~4-8），四重约束逐一判定航点 q 与面片 T_j：
- 成像距离（式 4-5）：D_min = max{d_s, d_cmin} ≤ 距离 ≤ D_max = d_cmax，且**对面片中心和三个顶点分别校验**；
- 相机姿态角（式 4-6）：由航点指向面片中心的方向反算所需云台偏航 ψ_g=arctan(Δy/Δx)、俯仰 θ_g=arctan(Δz/√(Δx²+Δy²))，须落在云台限位内；
- 视场角（式 4-7）：视场按**圆锥**近似，面片三顶点相对航点的方位/俯仰角须在 ±HFOV/2、±VFOV/2 内；
- 可见性（式 4-8）：视线方向 d_j = c_j − q0 与法向量满足 **n_j·d_j < 0**（从正面看）。

汇总为**可巡检性矩阵 M**（M_ij ∈ {0,1}，式 4-9），删除全零行航点 → P_ins。仿真中 P_safe 2369 点 → P_ins **87 点**（−96.3%）。

**④ 多指标优化**（p38–41）：
- 覆盖率 C(P) = 已覆盖面片数/N（式 4-10）。单指标问题 = **集合覆盖问题**：min |P| s.t. C(P)=1，用**贪心算法**（表 4-1，p39）：每轮选覆盖率增益 G(q_i)=|未覆盖集合中 M_ij=1 的面片数| 最大的点，直至全覆盖。仿真得 P_cover **4 点**——最少但成像质量不均（平均增益较 P_ins 降 22.93%）。
- 联合优化（式 4-12~4-17）：成像质量 Q(q_i,T_j) = ω1·f_d + ω2·f_θ（ω1+ω2=1），其中
  - **清晰度** f_d = (D_max − d_j)/(D_max − D_min)（离面片中心越近越清晰，归一化）；
  - **视角合理度** f_θ = arccos(n_j·d_j/(‖n_j‖‖d_j‖))/π，`[?]` 原文称"夹角为 180°（正对面片）时最大合理度"并限定 f_θ∈(π/2, π]，即取视线与法向的**钝角夹角**归一化——正对时夹角=π，f_θ=1。文中该式与文字说明存在符号含混（arccos 值域 [0,π] 与"180°最大"的表述需按钝角段理解）；
  - 联合增益 G_all(q_i) = G_ψ(q_i) + λ0·Q(q_i,T_j) − λ1·|P|（式 4-17，λ0+λ1=1），**加权贪心**（表 4-2）。仿真得 P_syn 18 点，覆盖率 100%，平均成像质量较 P_ins **+32.57%**。
- **局部航点融合**（p41，式 4-18）：距离 **<10 m** 的点归为冗余点集，按各自成像质量增益加权平均坐标融合为一点；**融合后重新验证覆盖率，若掉到 <100% 则取消该次融合**。仿真 P_syn 18 → P_search **11 点**（质量 −2.36% 换冗余清除）。

**航点流水线总账（仿真，表 4-4，p49）**：11520 → 2369（安全）→ 87（可巡检）→ 18（综合优化）→ 11（融合），覆盖率全程 100%。实物（微缩风机，§5.4.1）：4752 → 23 → 20 → 4 → **2 点**（拍摄距离 0.7~5 m，禁飞球 0.7 m，安全距离 2 m）。

#### 4.3.2 轨迹规划与跟踪（§4.3）

六步流程（p42）：设起止点 → 最邻近连接成初始航线 → 逐段碰撞检测 → 碰撞段插安全过渡点 → 重复 → 三次多项式插值 → 混合控制跟踪。

- **起止点**（p42）：起点 = 正视拍摄点；**终点 = 最后一个航点正上方 2 倍安全距离处**（避免返航撞风机）。
- **初始航线**：从起点开始**贪心最近邻**连接（优先最近未连接点），不重复，至终点。
- **碰撞检测**（式 4-19，p43）：线段 q_i q_{i+1} 到禁飞球球心的距离 `d_fly = ‖(q_{i+1}−q_i) × (P_hub−q_i)‖ / ‖q_{i+1}−q_i‖`（叉积模/弦长 = 点到直线距离）。大于球半径保留，否则进入修补。
- **安全过渡点**（式 4-20，p43）：碰撞点 Q_v 的法向 n_v = Q_v − P_hub，**Q_s = Q_v + d_safe·n_v**，d_safe 取禁飞区半径。对过渡点再做碰撞检测并迭代。
- **轨迹优化**（式 4-21，p44）：相邻航点间构造 `P(t) = at³+bt²+ct+d, t∈[0,T]` 的三次多项式。`[?]` **边界条件（首末速度/加速度约束）论文未给出**；图 4-6 画的是单位立方体上的贝塞尔曲线控制点示意，与式 4-21 的关系未说明——插值实现的细节是缺失的。
- **混合控制**（式 4-22~4-24，p44–45）：
  - "位置控制"：PID 输出**速度指令** v_cmd = Kp,p·e_p + Ki,p·∫e_p + Kd,p·ė_p（e_p = p_des − p）；
  - "速度控制"：PID 输出**加速度指令** a_cmd = Kp,v·e_v + Ki,v·∫e_v + Kd,v·ė_v；
  - **混合**：u_cmd = (1−α_vp)·v_cmd + α_vp·a_cmd，权重分段（式 4-24）：|q_{i+1}−q_i| > d_t 时 α_vp=1，否则 α_vp=|q_{i+1}−q_i|/d_t，d_t 为切换距离阈值。即**远离航点时段偏加速度（速度）通道保平滑，接近航点时线性滑向位置通道保悬停精度**。`[?]` 论文对"位置控制/速度控制"的命名与控制理论惯例（位置控制器输出速度指令）一致，但 α 的两端语义（α=1 全 a_cmd）与其"接近航点时增大位置控制比重"的文字描述方向相反，疑有笔误，需按代码意图理解。

**仿真结果（表 4-5/4-6，p51–52）**：初始航线 13 点、**碰撞点 12 处**、496.5 m；插过渡点后 25 点、0 碰撞、514.7 m（+3.66%）。跟踪对比：位置控制轨迹**碰撞点 10 个**（顿挫、斜向抖动大、多次进禁飞区）；速度控制平滑（平均曲率 −42.8%）但**悬停摇摆、大转弯偏差大**；混合控制轨迹 531.4 m、平均曲率 0.0501、最大曲率 0.9080，兼得两者。

#### 4.3.3 云台对正策略（§4.4，p45–47）

飞抵航点后的**视觉闭环微调**，目标是叶片中心线过图像中心（x/y 轴截距均为 0）：

1. 灰度化 + 高斯滤波；
2. **Canny** 边缘检测；
3. **概率霍夫变换**检测直线段，剔除短线段，保留斜率+截距；
4. 按（斜率，截距）用 **k-means 聚成两类**（叶片上边缘线/下边缘线）；
5. 每类中心取平均 → 叶片中心线方程（式 4-25：bx、by 为横纵截距，k_c = −by/bx）；
6. 云台姿态调整等效于相机坐标系旋转 R_C（式 4-26/4-27，俯仰/偏航两个旋转矩阵之积），旋转后新截距（式 4-28）：
   `b'_x = bx·cos(β0+Δβ) + by·sin(β0+Δβ)`，`b'_y = −bx·sin(α0+Δα) + by·cos(α0+Δα)`；
7. 令 b'_x = b'_y = 0，**闭式解**出云台偏航/俯仰调整量（式 4-29）：
   `tan(Δα+α0) = −bx/by`、`tan(Δβ+β0) = by/bx`（含取值域约束）。调整后重拍，迭代直至截距为 0。

与"无人机位置修正法"（其组内文献[70]）对比（表 4-7，p53）：修正精度相当（横/纵误差 0.76/0.54 m vs 0.70/0.61 m，均在 1 m 内），但**单次修正时间 1.63 s vs 5.88 s（−72.3%）**，且频繁调无人机位置的电耗远大于调云台。

### 4.4 第 5 章：实物实验（p55–64）

- **叶尖定位实验**（p58–59，表 5-4）：风机倒"Y"、偏航 −135°。因模型微小**忽略仰角锥角**。结果：偏航角误差 5.18°；三相位角均差 5.67°（系统偏移）；叶尖三轴平均误差 x/y/z = **0.082/0.079/0.037 m，最大 0.168 m**（亚米级达标）。注意角度误差比仿真（3.5°/2.24°）明显大。
- **航点实验**（p60–61）：4752 候选 → 2 个最终航点，覆盖率 100%。
- **轨迹实验**（p62–63，表 5-6）[V]（已回 PDF 核对表值）：初始航线 2 点/2 碰撞/6.0 m；安全航线 6 点/0 碰撞/6.55 m（+9.18%）；插值轨迹 6.73 m；**位置控制跟踪出现 2 个碰撞点**；速度控制悬停漂移"漂移到终点外较远距离"；混合控制 7.99 m、0 碰撞、跟踪效果最好。论文自评：模型太小、点少距近，**相对误差较大**。
- **巡检效果**：2 个航点利用五自由度拍多幅不同视角清晰图。

## 6. ★ 可迁移到 wt_inspection 的条目

> wt_inspection 现状要点（读码确认 [V]）：风机是**解析几何模型**（`WtTurbineSpec`：hubHeight/rotorDiameter/coneAngleDeg/tiltDeg/headingDeg/prebendM 等台账参数），站位沿叶片展向按 GSD/重叠率解析布设（非自由采样），安全模型是"静叶：到叶片轴线距离 > minSafeDistM；转动：保持叶轮圆盘之外（轴向分量 > 安全值）"，航线末端有六类危险航段统一修补，执行走 KMZ/wpml 航点（飞控执行，机载应用不控轨迹），`WtTurbine_SolvePhaseFromTip` 相位反解接口存在但**无人调用**，`park_phase` 已能解析未接通规划。

### 6.1 【高价值】相位角的视觉反解闭环 —— 给"唯一没接通的接口"提供现成算法

- **论文做法**（p19–26）：正视图中提取叶片中心线斜率 → 测量相位角 → 三叶片 120° 先验加权（式 3-7）→ 联合仰角/锥角最小二乘修正。实测角度误差仿真 2.24°、实物 5.67°。
- **wt_inspection 现状**：`wt_turbine.h:112` 的 `WtTurbine_SolvePhaseFromTip`（"由实测叶尖位置反解相位角，粗模/视觉识别阶段使用"）无人调用；`park_phase` 未接通；停用角未知时按"12 点方向"假设并告警（README 已知限制第 1 条）。
- **差异**：论文是从零视觉建模（无台账）；wt_inspection 已有完整解析模型和叶尖反解几何，缺的是**给反解喂叶尖观测的前端**。
- **具体动作**：在 `wt_telemetry` 的视觉反解通道里，把论文的正视图叶尖提取（YOLO 或更轻的直线检测）作为观测源，输出叶尖 ENU 坐标喂 `WtTurbine_SolvePhaseFromTip`；把解出的相位写回 `park_phase` 的运行时值，替代"12 点方向"默认假设。**判据可全部落在 wt_core**：反解出的相位与假设相位的偏差、三叶片 120° 一致性检验（论文式 3-7 的思想）都是纯几何，可进回归测试。
- **代价与风险**：需要相机内参+取图链路（wt_inspection 目前无视觉模块，这是新增整块）；妙算3 无 GPU，YOLO 管线要重新评估（见 §7 冲突 2）。若只求"确认停用相位"这一件事，论文的**叶片斜率权重法**（Hough 直线 + 长度系数加权，式 3-3）比 YOLO 轻得多——一张正视图中三支叶片的直线簇在纯 C 里用简化霍夫也可做，与项目"失败可解释"的视觉哲学一致。**这是本论文对 wt_inspection 最直接的一条。**

### 6.2 【高价值】"冗余计算机制"的降级模式 —— 双判据 fallback 的设计模板

- **论文做法**（p21，p31）：偏航解算双通道——轮毂-机舱中心线法（主）+ 叶片斜率权重法（备），按"轮毂/机舱是否可见"自动切换；对照组因轮毂不可见出现 8 min 调节循环与持续偏离，本文零异常。
- **wt_inspection 现状**：安全与规划判据都是单一判据（如停用相位未知 → 单一假设 + 告警）；`WtRunner_ParkPhaseKnown` 只有两个状态（已知/未知）。
- **差异**：wt_inspection 的降级是"未知就按假设飞+人工确认"，论文的降级是"主判据失效就换一个物理上独立的备判据继续算"。
- **具体动作**：在相位获取这条链上引入第二条独立观测（例如 6.1 的直线法 vs 激光测距点反推），两条判据一致才写回 park_phase；不一致时的仲裁规则与告警文案写进 runner。抽象成通用模式：**任何"影响安全包线的输入量"都应有两类物理来源不同的观测通道**。
- **代价与风险**：低——这是结构设计而非新硬件；仲裁逻辑要进 wt_core 测试（否则就是"判据对 ≠ 接线对"的老坑）。

### 6.3 【中高价值】面片级可巡检性校验 —— 把"站位真的拍到了"变成可验证命题

- **论文做法**（p36–39，式 4-5~4-10）：航点-面片可巡检性矩阵 M（距离/姿态角/FOV/可见性四约束）+ 覆盖率 C(P)=1 作为**硬约束**；贪心优化与融合的每一步都**回头重验覆盖率**（融合后覆盖率掉了就回滚，p41）。
- **wt_inspection 现状**：站位沿叶片解析布设，`wt_plan` 有安全校验（minSafeDistViolations 等），**但没有"每个目标面片至少被一个站位覆盖"的显式校验**；叶片覆盖靠解析间距（overlapPct/bladeSpacingM）保证，是构造性保证而非验证性保证；粗模环绕的覆盖率（coarsePhotoCount 张照片是否拍全风轮盘）同样无校验。
- **差异**：wt_inspection 不需要论文的"自由采样+贪心"（其站位是解析解，更优），但**缺一个独立的验证器**。构造性规划和验证性校验分离，正是该项目"校验层的判据不该取决于谁在调用"原则的延伸。
- **具体动作**：在 wt_core 新增一个校验函数：把解析模型表面按论文 §3.4 离散为面片（塔筒 N_z×N_θ、叶片沿轴分段×环向 2~4 份即可，不必 192 片照抄），对每个 `WtPlanPoint` 用论文式 4-5~4-8 的四约束（其中"姿态角约束"换成 wt_plan 已有的 gimbalYawDeg/gimbalPitchDeg 与限位）判定 M_ij，**输出覆盖率报告进 `wt_plan_demo` 打印与 `wt_test_plan` 断言**。粗模阶段以"风轮盘面片覆盖率≥阈值"作为 coarsePhotoCount 的下界推导依据。改动集中在 `wt_plan.c`/`wt_camera.c` 的新增只读校验 + 测试，不动规划主流程。
- **代价与风险**：面片数 × 站位数是 O(N²)，但 wt_inspection 站位数十、面片数百，PC 侧秒级，无算力问题；风险是面片离散粒度选择不当会给出虚假的"100% 覆盖"——粒度参数要进配置并受严格解析约束（项目已有先例：未知键名拒绝启动）。

### 6.4 【中价值】PEC 模型对"仰角+锥角不可忽略"的量化佐证 —— 支持既有决策、校准参数

- **论文做法**（p32–33）：忽略仰角锥角（I 型）叶尖三轴误差 ≈2.6 m，而叶片最大宽度仅 2.04 m——**几何误差大于判读对象尺度**；PEC 型 1.1 m。
- **wt_inspection 现状**：`WtTurbineSpec` 已含 coneAngleDeg（典型 0~8）、tiltDeg（典型 3~6），`wt_turbine.c:44–51` 有范围校验；站位沿叶片"预弯/锥角自然跟随"（wt_plan.c:714）。
- **差异**：无——wt_inspection 已经走在论文论证的"正确侧"。这条的价值是**给 README 的参数必要性提供文献佐证**，并给出量级感：锥角/仰角缺失造成的叶尖误差是"米级"的，与 minSafeDistM 同量级，不是可忽略项。
- **具体动作**：无需改码。可在 README 的参数说明处引一句"文献（单正文 2025，p33）实测：忽略仰角/锥角引入 ≈2.6 m 叶尖误差，超过叶片宽度"。
- **代价与风险**：零。

### 6.5 【中价值】危险航段修补的对照实现 —— 论文式 4-19/4-20 与 wt_plan 修补的交叉验证

- **论文做法**（p42–43）：线段-球体碰撞检测（叉积求点到直线距离）+ 在碰撞点沿球面法向外推 d_safe 插过渡点 + 迭代复检。
- **wt_inspection 现状**：`wt_plan.c` 有整套危险航段修补（出壳→沿弧→换高，全程在安全圆柱面之外），覆盖六类危险段——**解析构造式，比论文的一次性法向外推强**（论文方法对"斜穿圆盘"这类长穿越段会插出一串串联过渡点，路径质量差且只在球模型下成立）。
- **差异**：模型不同（球 vs 圆柱面/圆盘），论文方法**不能替代**现有修补；但"修补后必须复检"（论文步骤 4：重复 2/3/4 直至无碰撞）与"融合/修补后回头重验覆盖率"的**回滚纪律**值得对齐。
- **具体动作**：在 `wt_test_plan` 里补一个用例：对每个修补后的航段，用**独立于修补逻辑的第二实现**（论文式 4-19 的线段-球距离，改造为线段-圆柱面判定）复算安全性——两个独立实现互检，正是该项目"检查要能区分'做了'与'看起来做了'"的方法论。
- **代价与风险**：低；仅测试代码。

### 6.6 【低价值，选摘工程数值】位姿修正器的人机工程参数

- **论文做法**（p22–23）：修正缓冲 5 s、位移限幅 ±10 m、偏航限幅 ±180°、位置收敛阈 1 m、姿态收敛阈 ±5°（0.0873 rad）。
- **wt_inspection 关联**：若将来实现 6.1/6.2 的闭环反解与位姿修正（尤其对接 liangzhourenwu 项目的视觉照准经验），这组数值是现成的初始量级：缓冲时间对应"改完等稳定再判"，阈值对应"收敛即停，防往复振荡"（论文对照实验里 8 min 死循环就是没有这套防护）。
- **具体动作**：作为未来 `wt_app_config` 视觉反解段的默认参数草稿，标注来源。
- **代价与风险**：零（数值系作者调参所得，未给灵敏度分析，只能当起点 `[?]`）。

## 7. 与 wt_inspection 的冲突点

1. **安全几何模型不同，不能混用**。论文禁飞区 = 轮毂球心、半径=叶长的**球体**（p10、p36）；wt_inspection 转动模式的包线 = **叶轮圆盘之外**（到旋转轴轴向分量 > 安全值）。球体在上下游方向远大于圆盘（半径 R 处球面轴向覆盖 ±R，而圆盘轴向是"整个上下游半空间都要离开轴"——两模型在轴向判据上甚至方向相反：球模型要求离球心 3D 距离大，圆盘模型只约束轴向分量、允许切向贴近）。照搬论文的球模型会把 wt_inspection 的合法站位（圆盘边缘切向近距）误判为危险；反之用 wt_inspection 的圆盘判据去审论文的航点也会互相打架。**两套模型各自服务不同工况（全静止 vs 可转动），迁移任何"安全"结论前必须先换算到本项目的包线语言。**
2. **控制接口层级不同**。论文的位姿修正器/混合控制工作在速度/加速度指令层（PX4 offboard），wt_inspection 是 KMZ 航点层 + PSDK 云台控制。论文的"实时修正"在 wt_inspection 里只能物化为**重规划重下发**或 **PSDK 云台角指令**，其闭环频率（秒级悬停修正）与 KMZ 执行模型不兼容。任何"迁移控制策略"的说法都止步于此。
3. **算力假设不同**。论文 21 TOPS + CUDA 跑 480P 30FPS；妙算3 无此算力 `[?]`。论文方法族里只有**不依赖学习的那部分**（Hough 直线、几何解算、贪心优化）可在妙算3 上做，且更应下沉到 wt_core 在 PC 侧预计算，机载只执行。
4. **锁机假设 vs rotatable 模式**。论文全程假设锁机静止（p11），允许飞轮毂正上方俯视点、允许航点离面片仅 d_s（如实物 2 m）；wt_inspection 默认要考虑风轮可转动，轮毂正上方恰是圆盘轴向分量≈0 的最危险点。论文的任何航点形态（俯视点、正视点、贴面站位）**只能在 `rotorMayRotate=false` 且停用相位已确认的前提下引用**。
5. **定位基准**。论文世界系原点=无人机上电点（仿真/实物均如此），叶尖坐标是相对起飞点的局部坐标；wt_inspection 全链 WGS84+ENU 切平面。借鉴其算法时所有坐标要先过 `wt_geometry` 的 WGS84↔ENU，不能把论文的"世界坐标"直接当 ENU 用。
6. **相机模型**。论文针孔+定焦+FOV 圆锥近似；wt_inspection 等效画幅 GSD + 变焦。式 4-5~4-7 的阈值逻辑可借，公式中的常量不能借。

## 9. 关键原文摘录

1. **巡检工况前提**（p11）："在风机巡检过程中，为确保巡检的安全性，必须使风机处于停机工况，此时桨叶处于顺桨状态。为简化计算模型，本文假设顺桨状态下桨距角误差可忽略不计，即单个桨叶平面始终与风轮平面保持垂直，桨距角始终为 90 度，并基于此开展后续研究。"

2. **禁飞区定义**（p10）："禁飞区 即风机运行时可能会涉及到的工作空间，一般定义为以风机轮毂中心点为球心、叶片长度为半径的球体。"

3. **对既有逐点拍摄式巡检的四条批评**（p5）："其一，现有研究未充分利用云台自由度和相机变焦功能……其二，沿叶片方向巡检，仅能巡检叶片的迎风背风面，对于叶片前后缘、风机其他部件无法进行拍摄……其三，巡检规划泛用性低，只能针对特定的姿态下（如倒"Y"型）的风机进行巡检；其四，少许航点被规划在了风机工作区域内，无人机在巡检过程中有与风机相撞的风险，具有安全隐患。"

4. **冗余计算机制的动机**（p31）："原因是轮毂像素占比过小或轮毂图像缺失，前者会导致无人机陷入往复的调节循环，调整时长可达 8min，耗时巨大，后者会导致像素坐标无法更新，所解算出的修正点位会大幅度持续偏离风机，而本文算法具有冗余计算机制，可规避这些问题。"

5. **忽略仰角锥角的代价**（p33）："由于忽略了仰角和锥角的存在，I 型的三轴平均误差在 2.6m 左右，但叶片的最大宽度仅为 2.04m，所以这可能导致后续规划的巡检点产生较大偏移，影响图像采集质量甚至造成安全事故。"

6. **叶尖定位实物精度**（p59）："对于风机偏航角及叶片相位角的测算，角度误差在 6°以内，叶尖定位结果中 x、y、z 三轴的平均误差分别为 0.082m、0.079m、0.037m，最大误差为 0.168m。多次实验表明……叶尖定位精度可达到亚米级，满足巡检的精度要求。"

7. **航点融合的回滚纪律**（p41）："最后将融合点替换到 P_syn 中，并计算此时 P_syn 的覆盖率，如果覆盖率仍为 1，保留该融合点，如果覆盖率不为 1，则取消融合，进行下一个冗余点集的融合。"

8. **混合控制的意图**（p44）："在接近航点时，增大位置控制比重，使得无人机能够精准悬停拍摄；在离开航点时，增大速度控制比重，使无人机能进行平滑连续的飞行。"

9. **仿真轨迹对比的核心数字**（p52）："采用位置控制时，无人机可以在巡检点进行较好的悬停，但无人机在飞行过程中会有顿挫……多次进入禁飞区……采用速度控制时……飞行连贯且安全……但悬停时不稳定，会出现左右摇摆现象……采用混合控制时，同时具备了飞行连续和悬停稳定的优点。"

10. **云台对正优于位置修正的理由**（p53）："本章的方法在修正速度上更占据优势，单次修正时间比无人机位置修正法减少了 72.28%，并且在飞行过程中频繁调节无人机位置对无人机的电量消耗要远超过调节云台姿态。"

11. **自述局限（动态扰动）**（p66）："本文针对停机状态下的风机进行巡检研究，真实情况下停机状态的风机会有微弱摆动，建议构建叶片运动预测模型，设计一种叶尖动态预测定位及航点动态规划算法。"——与 wt_inspection"未考虑风速下叶尖的动态摆幅，转动模式下 min_safe_dist 需按现场风速调大"的已知限制互为印证。

12. **自述局限（未进真实风场）**（p66）："由于实验条件限制，该巡检方案仅在仿真环境和实物模型环境中进行实验测试，未能在实际风电场中进行完整的实验测试。"

这篇论文与 wt_inspection 是**互补而非竞争**关系：它解决"没有台账、姿态随机、怎么把风机看清楚"（视觉定位链路 + 冗余降级 + 面片覆盖验证），wt_inspection 解决"已知几何、怎么把站位和安全包线算对"（解析规划）。能搬的是它的**可靠性结构**（双判据冗余、修补后复检、覆盖率回滚）和**验证器思路**（面片级可巡检性矩阵），不能搬的是它的**执行层**（混合控制、YOLO 管线）和**安全几何模型**（禁飞球——与叶轮圆盘包线不同语言，混用必出错）。
