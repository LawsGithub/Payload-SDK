## 2. 一句话结论

提出一套**离线两步迭代**（航迹点选取 ⇄ 航迹线排序）的全覆盖航迹规划框架——每面片候选航迹点区域（凸约束）内随机采样 + QP 二次优化选点，RRT* 算点对代价、LKH-TSP（r-opt + απ-接近度候选集）排线，交替迭代至收敛；再用 **EDLines 线段识别风机顺桨停机角、把整条航迹线绕塔筒轴整体旋转同一角度**实现在线矫正。全程 ROS 仿真 + 地面机器人缩比验证，**未在真实风场用真实航迹飞行**。

## 3. 研究问题与定位

### 3.1 它的动机（p.4-5）

手动无人机巡检的四个痛点：对飞控手要求高、人为因素影响成像质量、巡检路线凭经验无科学航迹线、**风电场磁场干扰 GPS 使近距离巡检不安全**。前三条 wt_inspection 已由 KMZ 自动航线解决；第四条是其做视觉惯性定位（第 4 章）的出发点。

### 3.2 第 1 章的算法综述与分类（p.7-9）——它的判断值得记录

- 规划空间表示两分法：**栅格法**（A*、D*，数据量大、更新容易）vs **图形法**（可视图、Voronoi、PRM，数据量少但更新困难）（p.7）。
- 算法两分法：**传统经典**（Dijkstra —— 时间/内存与结点数平方成正比，只宜 2D 静态；模拟退火；人工势场）vs **现代智能**（GA、A*、RRT*、PSO、ACO）（p.8）。
- 核心定位：**巡检航迹规划 = 画廊问题（AGP）+ 旅行商问题（TSP）两步**。引用链条：Gonzalez-Banos（随机画廊算法，传感器选点）→ Lin & Kernighan（LKH 启发式）→ Hover（AGP 允许冗余 + 后处理改进路径，水下船体检验验证，可处理 3D）→ Papadopoulos（带微分约束的渐近最优巡检规划）→ Galceran（覆盖路径规划综述）（p.8-9）。
- 它的切口：上述通用方法**没有**针对"风机 + 无人机悬停拍摄"这一特定场景给出完整可用的候选点约束形式化与两步交替实现，且风机停机姿态不确定导致规划出的航线必须可矫正。

### 3.3 与 wt_inspection 的定位对比

wt_inspection 的三阶段规划是**解析几何直接构造**站位（相位反解驱动、GSD/重叠率推导间距），不走"候选点采样 + 组合优化"。本文是"**采样 + 优化**"路线的代表——对 wt_inspection 而言，它最大的价值不在主算法（TSP 排序在相位驱动的解析航线里不存在），而在三处外围：**停机角在线识别与航线矫正（§4.5）、站位的凸约束候选域形式化（§2.6.2）、把拍摄约束写成超平面不等式（式 2-12/2-13）**。

## 4. 技术路线与方法（分章细读）

### 4.1 第 2 章：基于 3D 场景的航迹点设计

**航迹点模型**（式 2-1，p.16）：航迹点 = (x, y, z, pitch, yaw, roll) 六元组。因为"成像设备与无人机相对固定"，且巡检飞行速度慢，**认为俯仰角与滚动角接近零**——即航迹点实际只含位置 + 偏航角（相机朝向）。这与 wt_inspection 的"站位 + 云台俯仰（瞄杆顶）"建模一致，但本文把俯仰角硬性置 0（表 5-1 亦然），**云台俯仰完全不参与规划**——这是它建模上最大的简化（Z30 云台可自由俯仰，所以它敢这么简化；相机以固定俯仰"安装在无人机上"是 §2.6.2 FOV 约束推导的前提）。

**规划准则两分**（§2.3）：
- 已知模型：建模 → 约束出候选区域 → 区域内选点（三步，p.17）；
- 未知模型：信息熵增益选下一最优视点（式 2-9~2-11，可测性矩阵 N 由候选点×特征点构成，n_ij = m_i·v_j 或 0，选 I_j = Σ n_ij·ΔE_i 加权和最大者为下一航迹点，p.20-21）。风机外形尺寸已知，故走已知模型路线。

**约束条件**（§2.3.3，p.18-19）：
- 可见性：航迹点方向向量与面片法向量内积 < 0（式 2-2）；
- FOV：α = 2·arctan(h/2f)，β = 2·arctan(v/2f)，对角 γ 同理（式 2-4~2-6）；
- 可见范围锥、遮挡、景深、分辨率、运动约束（定性提及）。

**3D 模型**（§2.5，p.22-23）：对比体素模型（存储量立方级增长、缺处理工具）与面图形学模型（只需表面属性），选后者。SolidWorks 建模 → 导出 **.STL 三角网格**（含顶点坐标与法向量）。

**候选航迹点区域**（§2.6，p.24-27）——全文技术核心之一：

对每个三角形面片规划一片候选区域，两类约束（借鉴生成-测试法与合成法）：

(a) **平面约束**（式 2-12，p.26）：设航迹点 g=(x,y,z)，三角形三顶点 x_i，归一化法线 a_N，则

```
(g − x_i)ᵀ n_i ≥ 0            i = 1,2,3   （三个入射角分离超平面，保证视线与面片成锐角）
(g − x_1)ᵀ a_N ≥ d_min                     （最小安全距离板层）
−(g − x_1)ᵀ a_N ≥ −d_max                    （最大距离板层）
```

即候选区域 = 面片法向方向上一段 [d_min, d_max] 的板层，再被三个入射角超平面裁剪（图 2-11）。d_min/d_max 兼作安全距离与景深约束。

(b) **FOV 约束**（式 2-13，p.26-27）：相机以固定俯仰安装，FOV 下界约束候选空间上界，候选区域呈三角形截面；总采样空间是所有截面的并集、**不是凸的**，于是把空间**划分为 N_C 块相等的凸切片**，每片内用四个分离超平面（上、下、左、右边界，式 2-13）近似，逐片求最优。水平方向相机角约束忽略，靠把 d_min 取得足够高保证三角形完全可见。[?] 论文未给 N_C 的取值。

**航迹点选取**（§2.6.3，p.27）：
- 初次：每个面片的候选区域内**随机采样一个点**（简单快速）；
- 迭代：随机采样与 **QP 二次优化**结合（式 2-14~2-17）。目标函数（按原文文字，公式排版提取有损）：最小化当前航迹点 g_k 与 g_{k-1}（候选区域内旧位置）、前一个航迹点 g_p、后一个航迹点 g_s 距离平方的加权和——前两项通过把点移近而**缩短航迹线**，后一项**限制改进步长**（因为邻居也在动）。约束（式 2-15）与候选区域超平面完全一致（入射角 3 条 + a_N 距离上下界 + FOV 四条）。权重矩阵 B = diag(b_const, b_const, a_const + b_const)（b=邻居距离一般权重，a=权重变化惩罚），D = diag(d_const, d_const, d_const)。[?] 具体权重取值论文未给；该 QP 形式出自 Scott 的 Model-based view planning（文献[64]）。
- 航向：选出点后取 **g_k 指向面片中心 m 的方向**为航向（式 2-18）。[?] 公式印作 ψ_k = g_k − m，按语义应为 m − g_k（从无人机指向面片），疑为排印方向反写。

**本章判据小结**：把"拍摄质量 + 安全 + 可见性"全部写成**线性不等式组**，选点问题变成凸可行域内的采样与 QP——这是可整体搬到 wt_inspection 的形式化资产。

### 4.2 第 3 章：航迹线迭代优化（AGP ⇄ TSP 两步交替）

**框架**（§3.1，p.29-30）：第一步选出覆盖全部面片的航迹点集；第二步求经过所有点的不重复最短连接线（TSP）；以"连接到航迹线中相邻点的成本"评估航迹点质量，**能采样出使成本更小的点就重采样该候选区域，再重算航迹线**，两步交替直至最优（图 3-1）。

**约束**（§3.2.1，p.29-30）：航迹线总长（续航）、避障（航迹线不得穿过风机）、最小转弯半径与爬升约束（**仅口头提及**，未进入算法——后面实验的航迹线是折线，无平滑处理 `[V]`）。

**RRT* 初始化**（§3.3，p.31-34）：
- 用途不是全程规划，而是**给 LKH 提供航迹点对间的初始代价矩阵**（点对距离 + 无碰撞性）。选 RRT* 而非 A*/GA/RRT 的理由：树状搜索在 3D 快速连接点对上有优势，RRT* 有代价函数与重连。
- 改造：**采样空间限定为各候选航迹点区域，每个区域只取一个航迹点**。
- 两阶段：新点接入（近邻候选父节点中选代价最小且碰撞检测合格者）+ 随机树重布线（经新点的路径更短则改父节点）。代价值 = 欧氏距离。
- **碰撞检测**（§3.3.3，p.32-33）：障碍物简化为长方体（已知模型表面解析式可知）；两点同侧不撞、异侧则判"连接线与障碍物表面是否有交点"，有交点则该点对连接无效（需要绕行时 RRT* 的中间节点承担绕行，代价反映进矩阵）。
- **Kd-tree 加速最近邻搜索**（§3.3.4，p.33-35）：方差最大维度分割 + 中位数建树 + 超球面与超矩形相交性回溯，标准实现。

**LKH-TSP 全局优化**（§3.4，p.35-39）：
- TSP 模型（式 3-2~3-3）：L(R) = Σ c_ij·d_ij，闭合回路。
- **r-opt（k 值可变）**：k 值固定需反复试验平衡时间与质量，Lin-Kernighan 的 r-opt 按规则自动调 k。
- 四法则：连续性（x_i = (t_{2i−1}, t_{2i})，y_i = (t_{2i}, t_{2i+1}) 交替）、闭合性、**正趋向**（式 3-6：g_k = l(x_k) − l(y_k)，G_n = Σg_k，**只要求 G_n > 0，允许单次 g_k ≤ 0**——这是 LKH 高效率的关键，可跳出局部极小）、分离性（X∩Y=∅）。
- 六条选择限制（p.38）：首删边不能是当前最优边、y_i 必须来自候选集、i≥4 时 x_i 不能是前几轮的边、两轮结果相同则提前结束、优先 d(x_i)−d(y_i) 大的边等。
- **απ-接近度候选集**（§3.4.4，p.38-39）：最小 1-树（M1T）与最优回路有 70%~80% 的边相同，故以 M1T 为基础。对距离阵 D 变换 P_ij = d_ij + π_i + π_j（不改变最优解），用**次梯度优化**调 π 使 ω(π) = L_π(T_π) − 2Σπ_i 最大化（Held-Karp 下界）；边 e_ij 的 απ-接近度 απ(e_ij) = L_π(T_π + e_ij) − L_π(T_π) ≥ 0，属于 M1T 的边为 0。候选集按接近度升序构造，同值取 d_ij 小者；上轮与当前航迹线共有的边优先入集。
- **初始航迹线构造**（§3.4.5，p.39）：逐点扩展，优先满足"候选边 + απ=0 + 属于当前最优航迹线"三条，都不满足则随机。
- **迭代单元**：以 **5-opt 为基本操作**（basic move），内部搜索可行的 2/3/4-opt；搜索不动时来一次**打断操作**（break，非连续闭合 5-opt = 非闭合 2-opt + 非闭合 2/3-opt）。基本操作→打断→基本操作循环，两者都失效则本轮迭代完成；随后回到 QP 重采样航迹点，重跑 LKH。

**仿真实例**（§3.5，p.40）：Ubuntu + ROS + rviz，假设风机**顺桨停机呈倒 Y 型**。只给了"一次选点结果"与"最优航迹线"两幅截图，**没有航迹长度、航点数、耗时数字** `[V]`。

### 4.3 第 4 章：视觉惯性定位 + 停机状态识别与航迹矫正

**双目 VIO**（§4.2~4.4，p.41-52）：针孔相机模型、双目视差深度（式 4-4）、径向/切向畸变（式 4-5/4-6）；点特征 ORB、线特征 **EDLines**（ED 边缘 + 直线度提取 + Helmholtz 准则去伪 + RANSAC 去外点），线匹配用 LBD 描述子（距离/夹角/重叠长度/长度四条件）；IMU 测量模型、预积分（式 4-11~4-14）、初始化（陀螺仪零偏 → SVD 求速度与重力 → 重力方向优化）；后端为**紧耦合图优化**：点重投影误差 + 线重投影误差（Plücker 坐标 + Cayley 参数化，端点到投影线距离，式 4-25）+ IMU 预积分误差（式 4-26），Huber 核 + LM 求解；前端 EPnP + IMU 预测帧间跟踪、局部地图重投影匹配、**滑动窗口局部 BA**（固定窗口 + 局部窗口，图 5-9）。这一整章是标准 PL-VINS 体系的复述与组装，对 wt_inspection 无直接用途（M4T 自带定位），不展开。

**风机停机状态识别**（§4.5.1~4.5.2，p.52-54）——对 wt_inspection 最有直接价值的一段：

1. **预检位置**：飞至"正对风机机舱的安全位置"，拍风机正面图像（用 VIO 定位到位）。
2. **EDLines 提线 + 三步后处理**（论文称"清晰化"）：剔除像素长度过小的线段；距离接近的两直线按最小二乘拟合合并；再剔一次短线段。效果：杆塔线段更完整（图 4-13）。
3. **确认杆塔**：图像中"下边缘有端点且斜率接近 90°"的直线判为杆塔（风机大、正面拍摄时杆塔常超出图像下缘）。
4. **确认机舱与叶片**：杆塔线远离图像边缘的另一端 ≈ 机舱位置；以此端点为圆心做圆，在圆域内按三叶结构找"相互成 120° 左右"的直线组；遍历所有线，偏转角相近的归为一组，组平均角为该叶片偏转角。
5. **求偏转角**（式 4-27）：每条线由两端点 (x1,y1)、(x2,y2) 算 α_i = arctan((y2−y1)/(x2−x1))，α ∈ (−90°,90°)，组内取平均；再找**最高像素点的叶片直线**（即最接近竖直向上的那支叶片），按对顶角关系得停机偏转角 **γ = 90° − α**（式 4-28）。顺时针偏转为正、逆时针为负。
6. **航迹矫正**（§4.5.3，式 4-29，p.54）：叶片所在面视为 y 固定的平面，叶片旋转 γ，则**整条航迹线跟着旋转 γ**：

```
x' = x·cosγ + z·sinγ
z' = −x·sinγ + z·cosγ      [?] 原文提取两处均显示 "+ sinγ"，疑为排印丢负号；
y' = y                      旋转矩阵语义上 z' 应为 −x·sinγ + z·cosγ
```

即绕 y 轴（塔筒轴）的平面旋转，塔筒位置不动。

### 4.4 第 5 章：系统设计与实验

**硬件**（§5.1，p.55-57）：六旋翼 + Pixhawk（NuttX/PX4，自带三轴陀螺/加计/磁力计/GPS）+ 双目相机（720P、50 fps、USB3、基线可调，装机头）+ **禅思 Z30 云台相机**（30 倍光学/6 倍数码变焦、213 万像素、抖动 <0.001°）负责在航迹点拍缺陷图 + **Intel Joule 570x**（1.7 GHz 四核 Atom、4 GB RAM）存航迹线并执行矫正。标定链：张正友标双目内参 → imu_utils（Allan 方差）标 IMU → **Kalibr 联合标定**（相对位姿 + 时间差，最大似然估计时延）。

**软件框架**（§5.2，p.57-60）：离线全局规划（模型导入 → 候选区域 → 采样 → RRT* → LKH-TSP → QP 重采样交替 K<n 次，图 5-7）+ 在线矫正（VIO 定位到预定位置 → 识别停机态 → 估计偏航角 → 旋转航迹线，图 5-8）。明确说**输入的 3D 模型即参考停机状态的模型，矫正角是相对该模型的偏转**。

**模型预处理**（§5.3.1，p.61-62）：SolidWorks 网格在**机舱头部、叶根连接处**等非重点位置过密 → 用 **Materialise Magics 24.0** 简化；再按 Z30 成像范围（距 4~10 m，画面约 **10 m × 5 m**）调整，**保证每个网格边长 ≤ 5 m**（= 画面短边），以支撑"每网格至少被一个航迹点覆盖"。

- 迭代收敛实验：总迭代次数加大跑，**约 20 次后航迹线长度趋于稳定**（图 5-12，只有曲线图无数值表 `[V]`），故取 20 次。
- 覆盖率定义（式 5-1）：ρ = (a/b)×100%，a=模型表面网格数、b=航迹点数；**实验取网格数 876、航迹点数 876、覆盖率 100%**。⚠️ 两处矛盾：①表 5-1 面片数 1212 ≠ 正文网格数 876（可能为 Magics 简化前后，论文未说明）`[?]`；②式 5-1 方向可疑——若 b<a 则 ρ>100%，按语义应为"被覆盖网格数/总网格数" `[?]`。
- 依据《风力发电场检修规程》（DL/T 797-2012）：巡检时**顺桨停机并锁定**；按"旋翼无人机近距离(<10 m)巡检"要求规划。
- 规划结果图 5-13：航迹线 + 绿色箭头表示各点航向。**仍未给航迹总长/航点数/规划耗时** `[V]`。

**定位实验**（§5.3.3，p.63-66）：不在真实风场做（停机影响发电 + 危及风机安全），改用**北交大机械楼顶的缩比风场模型**；因无法取得飞行真值，定量实验放在 **Turtlebot 移动机器人**上（70 cm/s、180°/s 上限），以设定运动路线为真值，误差取均方根 er = √((x1−x2)² + (y1−y2)²)（式 5-2）。矩形路线 4 m × 7 m：
- **视觉惯性融合定位误差 ≤ 0.12 m**；
- 转弯处比纯视觉定位**小 0.255 m**（论证 IMU 对纯旋转跟踪失败的弥补）；
- 定性实验：真机绕单台风机模型飞一圈，VIO 轨迹连续无中断（图 5-19）；顺带构建点线稀疏地图（图 5-20）。
- ⚠️ 全部实验在缩比模型 + 地面机器人上完成，无真实风机、无真实风场电磁环境数据 `[V]`。

**停机识别与矫正实验**（§5.3.4，p.67-68）：
- 在机舱位置拍正面图，EDLines 识别：绿线=叶片、蓝线=杆塔、红线=干扰段；算得偏转角 **−29.75°**（单一样本）。
- 整条航迹线旋转同角度得矫正航线（图 5-22）。
- 耗时（表 5-2）：**停机状态识别 1.913905 s + 航迹线矫正 1.498216 s ≈ 3.4 s，总时长 < 4 s**，结论是"无人机在轮毂位置短暂停留即可"，满足实时性。

**第 6 章自认的不足**（p.70）：
1. **没做"自动沿航迹线飞行"的飞控**——只规划与矫正了航迹线，如何跟飞、航迹点处怎么拍照都留给未来；
2. 没做飞行中避障（只有规划期的静态碰撞检测）；
3. **全部是仿真/缩比实验**，与实际风场需求可能有差距。

## 6. ★ 可迁移到 wt_inspection 的条目（核心）

以下逐条按"论文做法（页码）→ wt_inspection 现状 → 差异 → 具体动作 → 代价与风险"展开。

### 6.1 停机角在线识别 + 航线整体旋转矫正（★最高价值，直接命中 park_phase 待办）

- **论文做法**（§4.5，p.52-54；§5.3.4，p.67-68）：飞至机舱正前方预定位置拍正面图 → EDLines 提线段 → 短线剔除/近线最小二乘合并两轮后处理 → 触底边且斜率≈90° 的线判为塔筒 → 塔筒顶端为圆心找互成 120° 的三线组 → 组内平均偏角 → 取最高叶片线得 γ = 90° − α → 整条航迹线绕塔筒轴旋转 γ（式 4-29）。识别 1.9 s + 矫正 1.5 s。
- **wt_inspection 现状**：`park_phase`（停用角）已能从配置解析但**尚未接通到规划调用**；停用角未知时按"叶片停在 12 点方向"假设并告警（README「已知限制」）。
- **差异**：wt_inspection 的停机角是**人工配置的先验**；论文给出的是**飞行中在线测量**的方案，且给出了从一帧正面图像到角度的完整可复现算法链（含杆塔/叶片的判别判据，这是最值钱的部分——不是 EDLines 本身，而是"哪条线是塔筒、哪组线是叶片"的几何判据）。
- **具体动作**：
  1. 在三阶段航线前加一个**"预检站位"**：机舱正前方、叶轮圆盘之外且满足静止模式安全判据（到叶片轴线距离 > min_safe_dist）的固定相对位置，高度取轮毂高度附近（保证三支叶片与塔筒都入画且叶片不超出画幅）；
  2. 视觉侧实现线段提取与三步判别（M4T 广角或变焦一帧即可；EDLines 可换成更简单的梯度+霍夫方案，判据不变）。项目"视觉刻意不用 OpenCV"的原则下，杆/叶都是高对比直线，纯 C 的线段检测可行；
  3. 把测得的 γ 写回 `park_phase`（12 点方向为 0 的相位约定，与论文 γ=90°−α 的"最高叶片与竖直夹角"语义对齐后换算），再调用既有规划器重算航线；或对已生成 KMZ 前的航点表做式 4-29 的绕塔筒轴旋转（塔筒即风轮中心竖直线，对应 wt_inspection 风轮参考系的 z 轴）；
  4. 顺手解决"park_phase 未接通"待办：接通时直接以在线测量值为默认来源、配置值仅作 fallback。
- **代价与风险**：
  - **KMZ 落差（最大）**：论文的矫正是在机载内存里即时改航迹线；wt_inspection 改航线 = **重新生成 KMZ + 重新上传**（实测 41 分片链路），预检位置悬停期间要完成"拍一帧 → 识别 → 重规划 → 重传 → 确认"全链路。识别本身秒级，但重传的耗时与失败重试需要设计；备选是**按已知离散档位（如每 30°）预生成多套 KMZ**，识别结果只做选择——把在线计算变成在线查表，规避重算。
  - 识别鲁棒性未经验证广度（论文只测了一个姿态、且在缩比模型/实验室光照下）；天空背景高对比，主要风险是**干扰线段**（论文用颜色区分绿/蓝/红线段说明确实存在误提）与**叶片被变桨到非典型顺桨形**时的 120° 判据失效。
  - 若风轮**可转动**（wt_inspection 的第二作业模式），此方法完全不适用——识别的是停机姿态，转动模式下唯一安全判据仍是"保持在叶轮圆盘之外"，两者不可混用。

### 6.2 站位候选域的凸约束形式化（入射角超平面 + 距离板层 + FOV 裁剪）

- **论文做法**（§2.6.2，式 2-12/2-13，p.25-27）：每个面片的站位可行域 = 3 条入射角超平面（视线与面片法向成锐角，实验取入射角 ≤30°）+ 法向距离 [d_min, d_max] 板层（4~10 m）+ FOV 四超平面（非凸时切成 N_C 凸片近似）。选点/移点时以式 2-15 同一组约束保证移动后的站位仍可行。
- **wt_inspection 现状**：站位由 GSD/重叠率解析算出，是**点**而非**域**；README 未提及入射角（视线与叶面法向夹角）约束。
- **差异**：解析站位没有显式容差空间——GPS 误差、悬停抖动、叶形误差吃掉多少裕度是隐性的；且叶片是翼型曲面，**斜视时有效 GSD 劣化**，论文用 30° 入射角上限显式管住了这一点，wt_inspection 的等效画幅 GSD 推导默认正视。
- **具体动作**：在 `wt_plan` 给每个站位附加一个**沿叶片法向的一维可行区间** [d_min, d_max]（两端由 GSD 与安全距离给出）与一个**入射角上限**（建议从 30° 起步，叶片弦向表面曲率大处更严）：
  1. 安全校验阶段增加"站位入射角"检查项（站位→目标点视线与叶面法向夹角），超限告警或移站位；
  2. **危险航段修补时复用**：现有修补（出壳→沿弧→换高）移动站位后，用同一组不等式验证"移完仍满足成像约束"，把修补从纯安全行为升级为"安全 + 成像双可行"；
  3. `wt_plan_demo` 报告里打印每站位的入射角与距离裕度，作为调参依据。
- **代价与风险**：低。全部是桌面可测的纯几何判据（符合 wt_core 分层）；风险仅在于翼型面元的法向在前后缘处剧变，若用简化平板面元，入射角在叶缘处会失真——按 wt_turbine 现有的解析叶面（非网格）计算时，取叶段局部弦平面法向即可，避免引入 STL 网格。

### 6.3 "每站位至少完整覆盖一个网格"的覆盖性核验思路

- **论文做法**（§2.3.4 式 2-8，p.20；§5.3.1-5.3.2，p.62-63）：网格边长 ≤ 成像画面短边（5 m）保证单点可完整覆盖一块；覆盖性指标 = 覆盖面积比 f = Σs_j,image / Ω（式 2-8）。
- **wt_inspection 现状**：重叠率 ↔ 站位间距推导保证采集密度，但没有一个"逐段核验覆盖率"的输出项。
- **差异**：wt_inspection 的推导是**密度充分性**论证；论文的式 2-8 是**事后核验**指标。两者互补——前者保证"拍得够密"，后者能报告"有没有漏"。
- **具体动作**：`wt_plan` 的叶片段按相位-展向划分等效面元（wt_turbine 已有风轮参考系，面元是现成的投影几何），对每个站位计算其实际投影覆盖的面元集合，报告未覆盖面元列表（沿展向的缺口比总百分比更有用）。工作量中等，判据全在桌面可测。
- **代价与风险**：主要成本是把"站位视锥 ∩ 叶片面元"的遮挡/投影算清（叶片间互相遮挡在 y 向投影里会出现，论文没处理这个，wt_inspection 的相位分段天然绕开大半）。风险低，收益是把 README 的"全覆盖"从推导结论变成逐点核验结论。

### 6.4 航段-障碍相交的解析测试（替代/加固离散采样检查）

- **论文做法**（§3.3.3，p.32-33）：航段避障不用采样，直接判"连接线与障碍物（简化长方体）表面是否有交点"，同侧/异侧先分流再求交。
- **wt_inspection 现状**：全航段扫描 + 修补穿越叶片扫掠区的段落（README「安全设计要点」）；实现细节（离散采样还是解析求交）README 未写明 `[?]`。
- **具体动作**：若现状为离散采样判交，把"航段 vs 安全圆柱面/叶片扫掠区"的判交改为解析式（直线-圆柱面、直线-旋转面求交是闭式的），消除采样步长漏检；判据进 `wt_core`，配"构造一条恰好擦盘的航段必须报警"的回归测试（与项目"连通域去掉 union 测试照样全绿"同形状的反向验证思路）。
- **代价与风险**：小；若现状已是解析判交则此条作废（动手前先查 `wt_plan.c` 的修补实现）。

### 6.5 不建议迁移的部分（明确排除）

- **RRT* + LKH-TSP + QP 两步迭代主算法**：wt_inspection 的航线由相位反解**直接构造**，站位顺序天然确定（沿叶片展向 + 相位分段），不存在 TSP 排序问题；两步迭代是为"自由采样选点"路线服务的。强行引入只会把确定性规划变成随机收敛过程，且 LKH/RRT*/QP 的算力需求（论文用 2.8 GHz x86 跑 20 轮迭代，未报耗时）对妙算3 不现实，对 PC 侧也是无谓复杂化。**保留结论：论文验证了"采样+优化"路线的可行性，但 wt_inspection 的解析路线在确定性、可测试性（wt_core 回归）上更优，不需要换轨。**
- **双目 VIO 紧耦合定位**（第 4 章主体）：M4T 自带 RTK + 视觉定位，PSDK 可订阅飞机位姿；风场电磁干扰 GPS 的论点对 M4T 的多传感器融合定位影响远小于论文的 Pixhawk+GPS 方案。自建 VIO 的工程量与妙算3 算力负担都不成比例。
- **SolidWorks/STL 建模 + Magics 简化**：wt_inspection 的参数化解析风机更轻且可微调；仅当未来需要逐面片精细覆盖（6.3 做深了）时才考虑网格模型，届时记住论文的教训：**非重点区域（机舱头、叶根）网格过密会传导成航点过密，必须先简化**（p.61-62）。

## 7. 与 wt_inspection 的冲突点

1. **连续轨迹 vs KMZ 离散航点**（最大的结构性落差）：论文隐含"机载持有航迹线、可即时整体旋转/重算"的执行模型（Intel Joule 存线并矫正，p.56-57）；wt_inspection 的执行单元是 KMZ/wpml 航点文件——修改航线 = 重新生成 + 重新上传（分片链路）。所有"在线矫正"类方法迁入前必须先回答"矫正结果如何变成新的 KMZ"，6.1 的"预生成多套 + 查表"是绕开方式。另外，论文 RRT* 生成的**绕障中间节点**在 KMZ 执行模型下必须显式下发为航点才有意义，否则飞控按航点直线插值飞行、中间路径不生效——这与 wt_inspection 已踩过的"弧线中间落回盘内"危险航段（README 六类典型危险航段之一）是同一问题的两种表述。
2. **安全模型不同**：论文的安全 = 静态距离带 [4,10] m + 规划期碰撞检测；wt_inspection 区分"叶片静止（离叶片轴线距离）"与"风轮可转动（离旋转轴轴向分量）"两种判据，且转动模式禁止进入叶轮圆盘。论文的 4 m 最小距离、倒 Y 停机假设**只在停机锁定模式有效**（其依据 DL/T 797-2012 也是停机检修规程）；把论文方法用于 wt_inspection 时必须圈定在静止模式。
3. **云台俯仰参与度**：论文把俯仰角置 0、航向随站位朝面片中心；wt_inspection 精确计算云台俯仰（瞄杆顶，−atan2 公式，且有 −90°~70° 限位与"上仰越界"余量问题）。论文的"航向 = 朝面片中心"与 wt_inspection 的 towardPOI/瞄顶体系不冲突（论文的 yaw 对应 wt 的机头对杆），但**其候选域不约束俯仰**——迁移 6.2 时俯仰可行性仍要按 wt_inspection 自己的 GIMBAL 限位体系校验，论文帮不上。
4. **算力与平台**：论文规划在 x86 PC 离线完成、机载只做识别与旋转（秒级）；妙算3（aarch64、glibc 2.31、非 root）跑不动 LKH 级优化，但识别 + 旋转 + 重传这类轻量在线计算在其能力内。迁移方案的算力分配应沿用论文的同款切分：**重规划在 PC/预生成，机载只做识别与选择**。
5. **验证深度差距**：论文所有实验在仿真/缩比模型上完成，其"覆盖率 100%"、"误差 0.12 m"、"矫正 <4 s"都不能直接当作真实风场预期值引用——wt_inspection 有真机飞行验证文化（ONDEVICE-CHECKLIST 清单），引用这些数字时必须注明出处条件。

## 9. 关键原文摘录

1. **两步迭代定位**（摘要，p.v）：
   > "基于采样出的航迹点，采用 RRT* 完成航迹点对间的初次代价计算，以 k 值可变的 r-opt 操作 LKH-TSP 算法进行航迹线的优化设计及优化，得到当前的最优航迹线；然后……计算出与相邻航迹点距离最短的航迹点集，再以此为基础重新规划最佳航迹线；两步交替进行直至得到能够不重复地经过所有航迹点的最优航迹线。"

2. **航迹点模型与俯仰简化**（p.16）：
   > "巡检无人机的航迹点可描述为：{x, y, z, 俯仰角, 偏航角, 滚动角}……无人机的飞行速度不能过快，无人机的俯仰角和滚动角认为接近为零。"

3. **覆盖性目标**（p.20，式 2-8）：
   > "f 为本次巡检风机叶表面与整体风机表面积之比……f 的比例越高，则代表当前这组航迹点的质量越优。"

4. **候选区域双约束的设计意图**（p.25）：
   > "从安全性考虑，需要约束安全范围，其最大-最小安全空间分别为 dmax 和 dmin；从可见性方面考虑，使无人机航向与三角形面片之间为锐角……"

5. **FOV 约束的凸化**（p.26）：
   > "由垂直照相机打开约束产生的总采样空间是在所有垂直方向上所有这些三角形截面的并集，而不是凸优化的。为了近似和凸出该问题……将空间划分为 NC 块相等的凸块。为每个切片计算最优值，以便找到全局最佳解决方案。"

6. **QP 选点的意图**（p.27）：
   > "前两个部分通过将航迹点移到更近的位置而缩短航迹线长度，而后两个部分则限制了改进步骤的大小，因为 g_p^{k-1} 和 g_s^{k-1} 也可能移近。"

7. **LKH 正趋向法则**（p.37）：
   > "只要保证 Gn>0 即可，允许 gk ≤ 0 的情况发生，这是 LKH TSP 算法高效率的保证之一。"

8. **M1T 与最优回路的关系**（p.38）：
   > "最优航迹线与最小 1-树有 70%-80% 的边是相同的，因此，可以基于最小 1-树选择最优航迹线的候选集。"

9. **停机角判据**（p.53）：
   > "在无人机正面获取的风力发电机图像中，有时杆塔会超出图像，即在图像下边缘有端点且斜率接近 90 度的直线可确认为代表杆塔的直线。……若直线 l 存在另外两条与其成 120 度的直线，则可将直线 l 记为代表风机叶片的直线，遍历所有直线，并将直线偏转角度相近的归为同一组，其平均角度为其代表叶片的偏转角度。"

10. **矫正语义**（p.54）：
    > "在 3D 空间中，风机叶片所在面可视为 y 值固定的平面，风机叶片旋转一定角度 γ，则航迹线跟随旋转 γ 度，可实现不同停机状态下的叶片巡检。"

11. **网格尺度标定**（p.62）：
    > "成像设备为禅思 Z30 云台相机，巡检时需要保持的最大和最小距离为 10 米和 4 米。并且……成像范围大致在 10m×5m。因此，对风机表面的网格进行再次处理，保证每个网格的边长不超过 5m，以保证全覆盖巡检的实现。"

12. **停机依据行业标准**（p.63）：
    > "根据《风力发电场检修规程》可知，巡检风机时会顺桨停机并锁定。对于全局航迹线的规划，根据旋翼无人机近距离(<10 米)巡检的要求进行航迹线的规划。"

13. **定位实验结论**（p.65-66）：
    > "在此实验中，使用视觉惯性定位算法的定位误差精度在 0.12 米以内。……尤其是在路线转弯处，视觉惯性定位的误差比纯视觉定位小了 0.255 米。"

14. **矫正实时性**（p.67-68，表 5-2）：
    > 停机状态识别 1.913905 s，航迹线矫正 1.498216 s。"总时长不超过 4 秒，旋翼无人机完全有能力停留足够的时间。"

15. **自认边界**（p.70）：
    > "本文仅对巡检的航迹线进行了规划及矫正算法研究，但无人机遵循航迹线的自动飞控及在航迹点处的拍照方法还需进一步研究。……本研究主要进行了航迹线规划相关的算法设计及仿真研究，与实际风场的需求可能存在差距。"
